Takeout Tasks to ICS

Turn a Google Takeout Tasks.json export into an .ics file you can import. The file stays in your browser. You do not sign in to Google, and your tasks are never uploaded. Checking a license key is the only network request, and it sends only the key.

    What this does, and what it does not

    Tasks are written as VTODO items, grouped by list. A second, optional file writes due dates as VEVENT entries for Outlook and Google Calendar, which often ignore to-do items. Import into Outlook or Apple Reminders has not been tested yet with this build.

    This is not the only way to do the conversion. Free command-line tools already exist, including takeout_prepper, gtask-exporthelper, and google-tasks-to-ical. The difference here is that you open a page, drop the official export, preview it, and download ICS, without installing Python or .NET.

    Google Takeout often leaves repeat rules incomplete. When a rule can be read, it is kept. When it cannot, that task is exported once and marked in the preview and in the file as X-RECURRENCE-INCOMPLETE.
